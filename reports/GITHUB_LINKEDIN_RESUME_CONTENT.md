## Resume Project Description

**Mental Health Risk Prediction Using Machine Learning**

- Built an end-to-end supervised ML classification pipeline to predict mental health risk using anxiety, depression, stress, loneliness, and self-esteem indicators.
- Performed data preprocessing, EDA, feature selection, train-test split, 5-fold cross-validation, and model comparison using Logistic Regression and Random Forest.
- Evaluated models using accuracy, precision, recall, F1 score, ROC-AUC, and confusion matrix; selected Random Forest based on weighted F1 score.
- Deployed the trained model using Flask and Streamlit with saved `model.pkl` and `label_encoder.pkl` artifacts.
- Documented responsible AI concerns including bias, fairness, ethical limitations, and why predictions should not replace professional diagnosis.
